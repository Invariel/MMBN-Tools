# Battle Network Deck Builder
Supports Mega Man Battle Network 1-6 (not 4.5)

## Features
- Lets you build folders for the various Mega Man Battle Network games, provides area information and trader information about where to acquire chips based on the best information I could scrape from the internet (About -> About).
- Follows folder-building rules for the various games.
- Checklist lets you see where you need to go at a glance
- Random Hand lets you simulate drawing *n* hands (1 - 10000) and get probability distributions about which chips come up, and how frequently you draw 1-5 chip hands.
